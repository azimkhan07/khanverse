SkillNest — Phase 2 Feature Roadmap

Next phase: what to build, why it's unique vs Fiverr/Upwork, and exactly what's required (infra + modules) — in build order. The goal: Indian local + technical marketplace with AI assistance, event-driven integration (webhooks), and optional microservices split.

North Star for Phase 2

Turn SkillNest from "a gig board" into "a verified local + online services marketplace with AI on every step" — seller trust via eKYC, buyer trust via escrow + AI-triage disputes, and reach via WhatsApp/SMS/Hindi-first UX which Fiverr & Upwork simply don't serve.

Milestone 0 — Foundation (enables everything)

  • INFRAProduction infra from server-configuration-roadmap #1–#8 (queue on Redis, cron, real SMTP, HTTPS, storage:link, caches).
  • EVENTSDomain events layer inside Laravel (OrderPlaced, OrderPaid, OrderAccepted, MilestoneDelivered, KycUpdated) + listeners. Keeps monolith simple today, becomes microservice/Webhook payloads tomorrow.
  • WHOWebhook delivery service (retry+signature) + incoming-signed webhooks (whitelist CSRF for payment/notification callbacks).

Webhook / Microservice / AI architecture (how it stays simple)

  • Rule 1 — events first, microservices later. Phase 2 starts inside the monolith with domain events (Milestone 0). Only split a service when one concern has independent scale/team (candidates: notification-service, ai-service, search-service, later payment-service).
  • Communication while split: HTTP JSON for sync (search, AI), Redis queue + events for async (notifications, webhooks). Webhook relay = outbound events → signed POSTs; ingress = signed/auth'd endpoints → jobs.
  • AI stack concrete:
    • FastAPI microservice (ai-service) exposing /suggest, /quote, /translate, /triage, /recommend, /moderate.
    • LLM via OpenAI/Anthropic/Gemini key (env); local Ollama+LLaMA & Whisper on optional GPU box for cost/privacy (KYC-content never sent to US clouds).
    • Laravel side: simple HTTP client + queued jobs; all AI calls ASYNC (never block order placement).
  • Webhook list to implement (define once, reuse for both monitoring + client integrations): order.created, order.paid, order.accepted, order.delivered, order.cancelled, project.milestone, kyc.updated, payout.processed.
  • Effort guides: S <1 wk, M 1–3 wks, L 4–8 wks per feature — a single full-stack dev can deliver the whole Phase 2 in ~3–5 months sequencing by milestone.
