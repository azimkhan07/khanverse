A. Infra & DevOps (foundation)

ItemWhy (business reason)HowEffort
1. Production queue (DB → Redis) + workersEmails, webhooks, AI jobs, notifications block the request today (queue=sync). Needed for reliable order mail, PDFs, scoring.Enable Redis (Laravel 9 native), set QUEUE_CONNECTION=redis, run php artisan queue:work under Supervisor; optional Horizon (L9 supports Horizon for Redis).M
2. Scheduler (cron)Auto escrow release timers, seller availability day rollover, KYC reminder, wallet settlement, invoice reminders.* * * * * php artisan schedule:run; write task classes in app/Console.S
3. Webhook relay (outgoing)Push order/payment events to Telegram/Slack/Discord for seller alerts; post to client's system.Custom WebhookDeliveryService with retry + signature; or Laravel 9 outbound package; DB table webhook_deliveries.M
4. Webhook ingress (incoming)Accept third-party callbacks: payment IPN (CCAvenue), eKYC/Digilocker, SMS DLR, WhatsApp status.Signed routes + VerifyCsrfToken whitelist; HMAC/secret validation; idempotent processing jobs.M
5. Object storage / CDNUploads (KYC docs, order docs, media) scale beyond one disk; public CDN for images.MinIO self-host or S3-compatible (q 2026: AWS/GCS/B2); keep local disk fallback.M
6. Search engineReplace slow LIKE search on gigs for typo-tolerant, fast results (jobs, services, sellers).Meilisearch (easy; PHP client) or OpenSearch. Sync via jobs on service save.M
7. AI GatewaySingle place to call LLM providers (OpenAI / Claude / Gemini / local) for suggestions, matching, moderation, translation.Laravel `Ai` microservice OR curated package; config API keys; rate limits + cost guardrails.S-M
8. Monitoring & alertingKnow when payments/webhooks break; error tracking in prod.Sentry or Flare; Laravel PULSE for queue/cache (L9: use spatie/laravel-health or pulse alternative); UptimeRobot.S
9. Cache + session to RedisMulti-server ready, faster settings/catalog reads (currently cache=file, session=file).REDIS_HOST/port config; SESSION_DRIVER=redis, CACHE_STORE=redis.S
10. CI/CD pipelineRelease webhooks/microservices/AI safely instead of manual deploy.GitHub Actions (lint, migrate check, build, tests) + deploy via rsync/Enovadeployer or Docker.M
11. Logging pipelineCorrelate requests across monolith + microservices (trace id).JSON logs → single file or Loki/S3; add request_id middleware.S
